# System-Threat-Forecaster
As part of the Machine Learning Practice (MLP) module under my Data Science diploma at IIT Madras, this project was developed for a Kaggle competition on system threat forecasting. The goal was to predict potential system security threats using real-world activity data. The project explores and compares multiple machine learning models—including Decision Trees, Random Forests, XGBoost, and LightGBM—to evaluate their effectiveness in identifying threat patterns and improving predictive accuracy in cybersecurity.

# 🚀 Objective
Predict the likelihood of a system being compromised based on various behavioral and environmental features using supervised learning techniques.

# 🔍 Workflow
+ Performed Exploratory Data Analysis (EDA) to uncover patterns and detect anomalies.

+ Applied data preprocessing, including encoding, imputation, and scaling.

+ Trained and evaluated multiple machine learning models.

# 🧠 Models Used
+ Decision Tree

+ Random Forest

+ XGBoost

+ LightGBM

Each model was evaluated on performance metrics like accuracy, precision, recall, and ROC-AUC.

# 📊 Results
+ Ensemble models (XGBoost and LightGBM) consistently outperformed simpler classifiers.

+ Feature importance analysis helped understand key indicators of threats.
